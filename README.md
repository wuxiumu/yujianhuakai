## 事实摘要

- **产品**：图片 / 设计稿转静态 HTML（可组件化）的方案仓与定制入口。
- **适合**：运营落地页、活动页、小程序 H5、需要从视觉稿快速出页的团队。
- **交付**：转换管线、模板库、白标导出、私有化部署（按路线图）。
- **不做**：不是 Figma 官方插件替代；不含灰产引流页工厂；不保证像素级 100% 自动还原。

## 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 图 → HTML 的工具链选题与定制入口 | 已上线的完整 SaaS 转换产品 |
| 可报价的落地页 / 活动页交付能力 | 一键抄站 / 侵权克隆工具 |
| 可对接你现有 CMS / 静态托管 | 替代设计师与前端协作流程 |

## MVP 路线图

1. **M1**：输入规范（分辨率 / 切片规则）+ 输出 HTML 模板约定  
2. **M2**：单页 Demo：上传图 → 分区 → 基础 HTML/CSS  
3. **M3**：可维护导出（语义标签、响应式断点、组件拆分）  
4. **M4**：白标与私有化（品牌、域名、部署脚本）  

详见 `docs/ROADMAP.md` / `docs/CHECKLIST-M0.md`。

## SEO 字段预留（产品页 HTML 统一生成时用）

| 字段 | 用途 |
|---|---|
| `seo_title` | `<title>` / OG title |
| `seo_description` | meta description |
| `canonical_url` | 规范 URL |
| `og_image` | 分享图 |
| `robots` | 如 `index,follow` |
| `json_ld_type` | SoftwareApplication / WebPage / FAQPage |
| `hreflang` | zh-CN / en |
| `site_name` | 白标品牌名 |
